013-255 堆叠器 纸盘 偏移 传感器 失败 

参考BSD:CH17.39

堆叠器 纸盘 偏移 传感器 未开启 在...后的规定时间内 堆叠器 偏移 电机 ON.

步骤

输入 the Diag 模式, 输入 DC330 [012-096/097/099/094] (堆叠器 偏移 电机 半/一半_CW/原位_CCW/半/一半_CCW/原位_CW) 和 转动 them ON, 和 移动 堆叠器 纸盘 后 和 forth.

执行 堆叠器 纸盘 移动 后 和 forth?

是  编号

关闭电源 和 检查以下项目：

  • The 连接 之间 装订器 D6主电路板 J8085 和 堆叠器 偏移 电机 J8974 用于 打开 电路, 短路 电路, 和 接触不良.

  • 检查传动齿轮的磨损和损坏.

如果未发现问题，按顺序更换以下零件: 但是, 每个 时间 零件 已更换, 检查 是否 失败 is 仍然 发生 和 恢复 零件/部分 如果 具有 编号 问题.

  • 堆叠器 偏移 电机 (PL 27.10)

  • 装订器 D6主电路板 (PL 27.29)

按停止键.

输入 DC330 [013-172] (堆叠器 纸盘 偏移 传感器) 和 转动 开启. 和 然后, 输入 DC330 [012-096/097/099/094] (堆叠器 偏移 电机 半/一半_CW/原位_CCW/半/一半_CCW/原位_CW) 和 转动 them ON, 和 移动 堆叠器 纸盘 后 和 forth.

执行 输出 显示 of 传感器 开关?

是  编号

关闭电源 和 检查以下项目：

  • The 连接 之间 装订器 D6主电路板 J8094 和 堆叠器 纸盘 偏移 传感器 J8901 用于 打开 电路, 短路 电路, 和 接触不良.

  • 传感器 执行器 用于 deformation 和 损坏.

如果未发现问题，按顺序更换以下零件: 但是, 每个 时间 零件 已更换, 检查 是否 失败 is 仍然 发生 和 恢复 零件/部分 如果 具有 编号 问题.

  • 堆叠器 纸盘 偏移 传感器 (PL 27.10)

  • 装订器 D6主电路板 (PL 27.29)

按停止键.

It 可以 considered 该 那里 已 编号 错误. 如果 问题 persists, 更换 装订器 D6主电路板. (PL 27.29)
