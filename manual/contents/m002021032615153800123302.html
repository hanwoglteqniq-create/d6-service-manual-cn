051-314 EDI 电路板 Download 模式 失败 

参考BSD:CH32.6

在...期间 EDI 电路板 downloading, it ended abnormally 和 设备 可以 仅 启动 in the Download 模式 at 开机.

此 失败 is a 子 系统 故障 和 其 occurrence cuts 关闭/脱离 the Intlk_+24VDC. (请参阅 BSD CH17.7)

原因/措施

  1. 关闭再打开电源.

  2. 检查 connections 之间 the CDM 主电路板 J107 和 the EDIM IF PWB J8181 用于 打开 circuits, 短路 circuits, 和 poor contacts.

  3. 输入 Download 模式 to 执行 EDIM EDIM IF Download.

  4. If Download 不是 已完成 successfully, 更换 EDIM IF PWB. (PL 74.37)
