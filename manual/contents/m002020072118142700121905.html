013-308 裁切器 Dust Box 互锁 打开 

参考BSD:CH37.2

It 已 已检测 该 裁切器 Waste Container 不是 installed.

步骤

输入 the Diag 模式, 输入 DC330 [012-305] 和 转动 开启.

Is the 显示 "L"?

是  编号

检查 Waste Container 设置 Intlk 开关 (PL 45.24) 用于 操作 故障. If 编号 问题 发现, 更换 裁切器电路板 (PL 45.35).

The Waste Container 和 the 开关 不是 好 aligned. 检查 用于 损坏 到 Waste Container 执行器.
