2.2.3.8 NIP/释放 电磁阀 不 Energized 故障 FIP 

步骤

(图 1) 2017

在执行...之前 此 FIP, 确保 那里 is 编号 (机械) 操作 故障 使用 电磁阀.

Is +24VDC measured 之间 the NIP/释放 电磁阀 销-1 (+) 和 the GND (-)?

是  编号

Is +24VDC measured 之间 the PWB 销-5 (+) 和 the GND (-)?

是  编号

检查 +24VDC 输入 的 PWB. If 编号 问题 发现, 更换 PWB.

检查 连接 之间 the PWB 销-5 和 the NIP/释放 电磁阀 销-1 用于 打开 电路 和 接触不良.

Use 以下 FIP 当...时 那里 is a 问题 使用 NIP.

输入 DC330 [XXX-XXX] 和 转动 SOL NIP ON.

Is +24VDC measured 之间 the PWB 销-4 (+) 和 the GND (-)?

是  编号

输入 DC330 [XXX-XXX] 和 转动 SOL NIP ON.

Is +24VDC measured 之间 the NIP/释放 电磁阀 销-3 (+) 和 the GND (-)?

是  编号

更换 NIP/释放 电磁阀.

检查 连接 之间 the PWB 销-4 和 the NIP/释放 电磁阀 销-3 用于 打开 电路 和 接触不良.

Use 以下 FIP 当...时 那里 is a 问题 使用 释放.

输入 DC330 [XXX-XXX] 和 转动 SOL 释放 ON.

Is the 电压 之间 the PWB 销-6 (+) 和 the GND (-) +24VDC?

是  编号

输入 DC330 [XXX-XXX] 和 转动 SOL 释放 ON. Is the 电压 之间 the NIP/释放 电磁阀 销-2 (+) 和 the GND (-) +24VDC?

是  编号

更换 NIP/释放 电磁阀.

检查 连接 之间 the PWB 销-6 和 the NIP/释放 电磁阀 销-2 用于 打开 电路 和 接触不良.

更换 PWB.
