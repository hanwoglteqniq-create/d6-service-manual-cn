012-222 Up 端部 导轨 原位传感器 关闭/脱离 失败 

参考BSD:CH38.6

当...时 the 上游 端部 导轨 is moving 从 其 原位 位置, the 上方 端部 导轨 原位传感器 不 关闭 在...后的规定时间内 上方 端部 导轨 电机 ON.

步骤

输入 the Diag 模式, 输入 上方 端部 导轨 原位传感器 (DC330 [013-121]) 和 转动 开启. Manually 移动 up/下 the 端部 导轨 to 关闭/ON 传感器.

执行 输出 显示 of 传感器 开关?

是  编号

关闭电源 和 检查 连接 之间 折叠器 PWB J8105B 和 the 上方 端部 导轨 原位传感器 J8806 用于 打开 电路, 短路 电路, 和 接触不良.

如果未发现问题，按顺序更换以下零件: 但是, 每个 时间 零件 已更换, 检查 是否 失败 is 仍然 发生 和 恢复 零件/部分 如果 具有 编号 问题.

  • 上方 端部 导轨 原位传感器 (PL 50.20)

  • 折叠器 PWB (PL 50.4)

按停止键.

输入 上方 端部 导轨 电机 (DC330 [013-029/030] (端部 导轨 Up/下)) 和 转动 开启.

执行 the 上方 端部 导轨 电机 操作?

是  编号

关闭电源 和 检查 连接 之间 折叠器 PWB J8107B 和 the 上方 端部 导轨 电机 J8812 用于 打开 电路, 短路 电路, 和 接触不良.

如果未发现问题，按顺序更换以下零件: 但是, 每个 时间 零件 已更换, 检查 是否 失败 is 仍然 发生 和 恢复 零件/部分 如果 具有 编号 问题.

  • 上方 端部 导轨 电机 (PL 50.20)

  • 折叠器 PWB (PL 50.4)

按停止键.

检查以下项目：

  • 检查传动齿轮的磨损和损坏.

  • 检查传动皮带的松脱、老化和张力不当.

  • 轴 sliding 章节 用于 the presence of grease. (PL 50.20)
