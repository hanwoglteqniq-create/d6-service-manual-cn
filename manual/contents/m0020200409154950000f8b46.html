6.2.4.2 HCS, EDIM Dimension 和 Weight 

标准 模块

  • Machine 尺寸: 800x725x1042 (WxDxH mm)

  • Machine Weight: 155.0kg or lighter

    (图 1) sa623001

    导轨 dimension 用于 the EDIM 后面 stage 设备 is 47.6 mm.

和/与 大容量堆叠器 Extension Kit: (和/与 Extension 导线)

  • Machine 尺寸: 1466x725x1196 (WxDxH mm)

  • Machine Weight: 157.0kg or lighter

    (图 2) sa623003

    如果 downstream 设备 is 装订器 D6, Extension 导线 纸盘 将 get in the way, so store it in the Holder 支架 和 the 导线 Holder on 装订器 D6 or keep 开启 HCS 顶部 盖板.

和/与 大容量堆叠器 Extension Kit: (和/与 Corrugation 导线)

  • Machine 尺寸: 1233x725x1227 (WxDxH mm)

    (图 3) sa623004

    如果 downstream 设备 is 装订器 D6, Extension 导线 纸盘/Corrugation 导线 纸盘 将 get in the way, so store it in the Holder 支架 和 the 导线 Holder on 装订器 D6 or keep 开启 HCS 顶部 盖板.
