012-327 IFM 子 CPU Download 模式 失败 (Apeos C8180/C7580/C6580, ApeosPro C810/C750/C650) 

参考BSD:CH31.6

当...时 the IFM controlling 子 CPU 已 downloading 数据, it ended abnormally 和 可以 仅 启动 in the Download 模式 at 开机.

此 失败 is a 子 系统 故障 和 其 occurrence cuts 关闭/脱离 the Intlk_+24VDC. (请参阅 BSD CH17.7)

原因/措施

  1. 关闭再打开电源.

  2. 检查 连接 之间 装订器 D6主电路板 J8067B 和 IFM PWB J8161B 用于 打开 电路, 短路 电路, 和 接触不良.

  3. 输入 Download 模式 to 执行 IFM controlling 子 CPU Download.

  4. If Download 不是 已完成 successfully, 更换 IFM PWB. (PL 73.3)
