013-222 裁切器 Nip 辊 底部传感器 On 失败 

参考BSD:CH37.13

裁切器 Nip 辊 底部传感器 未开启 在...后的规定时间内 裁切器 Nip 辊 电机 ON.

步骤

关闭 机器. 打开 裁切器 顶部 右侧 盖板 和 拆卸后盖板.

输入 the Diag 模式, 输入 DC330 [014-076] (Nip) 和 DC330 [014-077] (释放) 和 转动 them ON alternately.

可以 you hear 裁切器 Nip 辊 电机 操作 sound?

是  编号

关闭电源 和 检查 连接 之间 the 裁切器电路板 J8513 和 裁切器 Nip 辊 电机 J8651 用于 打开 电路, 短路 电路, 和 接触不良.

如果未发现问题，按顺序更换以下零件: 但是, 每个 时间 零件 已更换, 检查 是否 失败 is 仍然 发生 和 恢复 零件/部分 如果 具有 编号 问题.

  • 裁切器 Nip 辊 电机 (PL 45.30)

  • 裁切器电路板 (PL 45.35)

按停止键.

检查 输出 (UI 显示) of 裁切器 Nip 辊 底部传感器 (DC330 [012-268]) 当...时 裁切器 Nip 辊 电机 Released (DC330 [014-077]) or Nipped (DC330 [014-076]).

  • 输出 (显示) of 传感器 在...期间 电机 释放: 低

  • 输出 (显示) of 传感器 在...期间 电机 Nip: 高

是 the 显示 as described 以上?

是  编号

关闭电源 和 检查 连接 之间 the 裁切器电路板 J8503 和 裁切器 Nip 辊 底部传感器 J8663 用于 打开 电路, 短路 电路, 和 接触不良.

如果未发现问题，按顺序更换以下零件: 但是, 每个 时间 零件 已更换, 检查 是否 失败 is 仍然 发生 和 恢复 零件/部分 如果 具有 编号 问题.

  • 裁切器 Nip 辊 底部传感器 (PL 45.30)

  • 裁切器电路板 (PL 45.35)

按停止键.

检查以下项目：

  • 检查传动齿轮的磨损和损坏.

  • 不正确的 ...的安装 裁切器 上方 辊.
