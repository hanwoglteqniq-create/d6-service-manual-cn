REP 45.5.1 Opening 和 Closing the 顶部 右侧 盖板 和 顶部 左侧 盖板 

参考 PL:PL 45.5

Removal

执行IOT关机步骤. 确认电源已关闭并拔掉电源插头.

  1. 拆卸方背折叠裁切器的电源线支架.

  2. 拔出方背折叠裁切器的电源线.

  3. 分离方背折叠裁切器. (REP 45.1.1)

  4. 拆卸 前面 上方 盖板. (REP 45.2.1)

  5. 打开 the 顶部 右侧 盖板. (图 1)

    1. 插入 5.5 mm Box Driver 没有 snagging the 线束 in the 顶部 中央 盖板 (PL 45.6).

    2. 打开 the 顶部 右侧 盖板 by pressing the Button 当...时 pressing the 链接 using the tip 的 5.5mm Box Driver.

    (图 1) tm44533

  6. 打开 the 顶部 左侧 盖板. (图 2)

    1. 打开 the 顶部 左侧 盖板 by pressing the Button 当...时 pressing the 链接 using the tip 的 5.5mm Box Driver.

    (图 2) tm44534
