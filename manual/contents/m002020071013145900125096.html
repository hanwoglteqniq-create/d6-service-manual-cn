024-931 装订针 Dust 满载/完整 

参考BSD:CH17.36

  • 在...之后 装订针 Dust 附近 满载/完整, 装订针 Valid 计数 具有 reached the predefined 值.

  • 在...之后 it 已 已检测 该 装订针 Waste Container 已有 been removed 然后 installed, the 附近 满载/完整 传感器 未开启 甚至 在...之后 the valid 计数 已有 reached the predefined 值. The valid 计数 指示 the 号码 of 装订针 用于 80 or 更少 纸张 of 纸张.

原因/措施

  1. 拆卸 纸张 dust 从 the Waste Container.

  2. 检查 值 of NVM [763-331] (Dust 满载/完整 检测 在...之后 装订针 附近 满载/完整). (默认值: 4000)

  3. 输入 装订针 Waste Container 附近 满载/完整 传感器 (DC330 [012-229]) 和 转动 开启. (PL 27.5)

    • 打开 装订针 Waste Container 附近 满载/完整 传感器 (DC330[012-229]), 和 put 纸张 nearer to 传感器 灯/光线 receptor 零件/部分 to 检查是否 输出 显示 of 传感器 切换.

  4. 如果未发现问题，更换装订器 D6主电路板. (PL 27.29)
