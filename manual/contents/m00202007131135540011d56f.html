013-250 打孔 子 CPU 通信 失败 /堆叠器 防篡改 子 CPU 通信 失败 

参考BSD:CH17.12, CH17.44

  • 通信 错误 之间 the 主 CPU 和 打孔 子 CPU 具有 occurred.

  • 通信 错误 之间 the 主 CPU 和 堆叠器 防篡改 子 CPU 具有 occurred.

If 堆叠器 防篡改 不是 installed, follow [步骤 a].

If 堆叠器 防篡改 已安装, 检查 值 of NVM [516-590] (检查 内容 of 堆叠器 防篡改 Fault). 如果 值 的 最后一个 7th 数字 is 0, follow [步骤 a]; 如果 is 1, proceed 按照 [步骤 b].

原因/措施

[步骤 a]

012-333 请参阅 FIP (打孔 子 CPU Download 模式 失败).

步骤

[步骤 b]

  1. 关闭再打开电源.

  2. 检查 连接 之间 装订器 D6主电路板 J8088 和 堆叠器 防篡改 PWB J8267 用于 打开 电路, 短路 电路, 和 接触不良.

  3. 如果未发现问题，按顺序更换以下零件. 但是, 每个 时间 零件 已更换, 检查 是否 失败 is 仍然 发生 和 恢复 零件/部分 如果 具有 编号 问题.

    • 堆叠器 防篡改 单元 (PL 27.34)

    • 装订器 D6主电路板 (PL 27.29)
