安装步骤

  1. 打开 the package 该 comes 使用 CDM 和 检查 bundled/separate order items.

  2. 关闭IOT主机和打印服务器, 拔掉电源.

    用于 如何 to 关闭电源, 请参阅 the 维修 手册 用于 IOT 和 打印服务器.

  3. 拆卸 packing tape 从 外部 机器的.

  4. 打开 the 前面 门 和 拆卸 securing ribbon (前面/后面) 和 tape of 滑槽.

  5. 拆卸后下盖板. (PL 43.1a)

    1. 拆卸螺钉（x4）.

    2. 拆卸后下盖板.

    (图 3) cd910001

  6. 安装 板 Shield 组件. (PL 43.2)

    1. 安装 板 Shield 组件 (x2).

    2. 安装 螺钉 M3x7 (x2).

    (图 4) cd910003

  7. 安装 对接 板 to IOT.

    1. 安装 对接 板.

    2. 固定 it using 螺钉 M4x16 (x2).

    (图 5) cdw910003

  8. Temporarily 拆卸螺钉 该 secures the Latch Stopper.

    (图 6) cd910005

  9. Paste Label 编号3 向右 盖板 组件 of IOT.

    (图 7) ifm910009

  10. 对齐 hooks 的 对接 板 到 对接 slots 的 CDM 和 push it in 直到 they 锁定.

    • 如果 hooks 的 对接 板 请勿 match the 高度 的 对接 slots 的 CDM, 执行 步骤 11 to 调整 高度 的 CDM Caster.

    (图 8) cdw910004

  11. Use the provided wrench to 调整 高度 的 CDM Caster as 所需的.

    1. 拆卸螺钉 和 拆卸 wrench.

      (图 9) cd910014

    2. Caster to be adjusted (前面 侧面).

      (图 10) cd910006

    3. Caster to be adjusted (后面 侧面).

      (图 11) cd910007

    4. 松开 the securing 螺母 of 每个 caster using the wrench.

    5. [前面 侧面, 上游]

      转动 adjusting 螺母 using the wrench 和 调整 高度. (图 12)

      [前面 侧面, downstream, 后面 侧面 (x2)]

      Use the wrench to 转动 Hexagonal 螺栓 和 调整 高度. (图 13)

    6. 拧紧 the securing 螺母 of 每个 caster using the wrench.

      (图 12) ia90011

      (图 13) ip910018

    转动 hexagonal 螺栓 using the provided wrench.

    (图 14) ifm910011

    如果 is difficult to work 使用 provided wrench, use the ratchet wrench.

  12. 固定 the Latch Stopper by using 螺钉.

    (图 15) cd910005

  13. 连接 CDM 到 subsequent 设备 using the I/F 电缆.

    [示例： 用于 HCS 连接]

    1. 连接 lattice 连接器 to 连接器 1 (P306).

    2. 连接 lattice 连接器 到 HCS.

    (图 16) sa910002

  14. Reinstall the 后面 下方 盖板 该 已 removed in 步骤 5 in the reverse order.

  15. 连接电源线.

    1. 插头 电源线 进入 the 入口.

    2. 安装 电源线 Protector 支架 using 螺钉 M3x7.

    (图 17) cd910008

  16. 连接 CDM to IOT by using the I/F 电缆 (短路).

    1. 连接 lattice 连接器 to IOT.

    2. 连接 lattice 连接器 to 连接器 (P305).

      (图 18) cdw910005

  17. [用于 新 installations]

    打开电源 of IOT 和 go to 步骤 19.

  18. [如果发生 machine 更换 of CDM in Interposer 安装 配置]

    打开电源 of IOT 和 执行 以下.

    当...时 changing the CDM 设备 用于 Interposer-installed configurations, the Interposer 纸盘 尺寸 传感器 analog 调整 值 应 loaded 到 CDM/装订器 D6 和/与 以下步骤.

    1. 输入 the CE 模式, change the 值 of NVM 769-546 从 0 to 1.

    2. 出纸 CE 模式 和 转动 关机 然后 ON.

  19. 检查 操作 的 CDM.

    1. 检查 状态 of 纸张 传输, 用于 异常 噪音, 和 等.

      确认 纸张 不 get 卡住的, torn, contaminated, folded, or creased.

    2. [当...时 长 纸张 is supported]

      If an 错误 occurs, 执行 Steps 20 to 23.

  20. [当...时 长 纸张 is supported]

    关闭 IOT.

  21. [当...时 长 纸张 is supported]

    释放 对接.

  22. [当...时 长 纸张 is supported]

    调整 对接 调整 板.

    1. 松开螺钉 在后面.

    2. 拆卸螺钉 在前面, 和 reposition it 到 长 hole.

    3. 调整 对接 调整 板 按照 the 表 以下.

      纸张 不对齐 方向

      移动 方向 of 调整 板

      前面 方向

      前面 方向 (a)

      后面 方向

      后面 方向 (b)

    4. 固定 the 螺钉（x2）.

      (图 19) ff910046

  23. [当...时 长 纸张 is supported]

    执行 对接 再次 和 启动 超过 从 步骤 17.

  24. Create a report 和/与 以下 Mod 编号

    接口消卷器 D1: 804V
