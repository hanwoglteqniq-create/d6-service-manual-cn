ADJ 46.12.1 Interposer 纸张 宽度 Adjustment/读取 Analog 值 

目的

此 调整 已 已执行 at shipment, 但是 the 调整 应 已执行 再次 安装时 另一个 Interposer, 这样的 as 在...期间 Interposer replacement/substitution, or 当...时 the CDM 主电路板 已更换, or 当...时 装订器 D6主电路板 已更换.

The analog 调整 values of Interposer 是 stored in the NVM in-built in the CPU 的 IP PWB at shipment. At the 时间 of 安装 or in the circumstances described 以上, it is necessary to 读取 the analog values stored in the IP PWB CPU in the NVM 的 CDM or 装订器 D6. The NVM 用于 adjusting the IP 纸盘 尺寸 传感器 analog 值 和 the 概述 的 调整 是 described 以下.

[Reading 和 saving analog 值 当...时 CDM is the 连接 destination]

  • 适用机型: ApeosPro C810G, Apeos C8180G, Apeos 7580G, RP EC1100, RP SC180G

[检查]

  1. NVM[769-544]: IP 纸盘 尺寸 传感器 Analog 值 读取 (用于 use 安装期间)

    • 默认值 [1] (Setup 范围: 0 to 1)

      • 0: 请勿 执行 analog 值 读取 (请勿 save)

      • 1: 执行 analog 值 (factory 默认值) 读取. (请勿 save)

      • 2: 执行 analog 值 (调整 值 at 安装 位置) 读取.

      在...之后 the NVM is saved, 此 将 automatically be 设置 to '0'.

      安装时, 连接 CDM 和 Interposer, 和 the analog 值 从 the NVM in-built in the IP PWB CPU 将 automatically written 到 CDM NVM 以下 当...时 电源 已开启.

      [当...时 the CDM is the 连接 destination]

      • NVM 769-500: IP 纸盘 尺寸 传感器 侧面 导轨 最小 位置 Analog 值 (默认值: 634)

      • NVM 769-501: IP 纸盘 尺寸 传感器 侧面 导轨 最大 位置 Analog 值 (默认值: 71)

  2. NVM [769-546]: IP 纸盘 尺寸 传感器 Analog 值 读取 (用于 use 当...时 CDM 已更换)

    • 默认 [0] (Setup 范围: 0 to 2)

      • 0: 请勿 执行 analog 值 读取

      • 1: 执行 analog 值 (factory 默认值) 读取. (设置 当...时 the CDM 已更换 在...之后 安装)

      • 2: 执行 analog 值 (调整 值 at 安装 位置) 读取.

      在...之后 the NVM is saved, 此 将 automatically be 设置 to '0'.

      更换后 the CDM, 连接 CDM 和 Interposer, 出纸 Diag 模式 在...之后 设置 上述 NVM, 关机 和 ON, 和 the analog 值 从 the NVM in-built in the IP PWB CPU 将 automatically written 到 CDM NVM 以下.

      [当...时 the CDM is the 连接 destination]

      • NVM 769-500: IP 纸盘 尺寸 传感器 侧面 导轨 最小 位置 Analog 值 (默认值: 634)

      • NVM 769-501: IP 纸盘 尺寸 传感器 侧面 导轨 最大 位置 Analog 值 (默认值: 71)

  3. NVM[769-545]: IP 纸盘 尺寸 传感器 Analog 值 Save (用于 use 当...时 Interposer 已更换)

    • 默认 [0] (Setup 范围: 0 to 1)

      • 0: 请勿 执行 analog 值 save

      • 1: 执行 analog 值 save. (设置 当...时 Interposer 已更换 在...之后 安装)

      在...之后 the NVM is saved, 此 将 automatically be 设置 to '0'.

      更换后 the Interposer, 连接 CDM 和 Interposer, 和 在...之后 设置 上述 NVM, 确认 analog 值 (最大 位置/最小 位置) 的 IP 纸盘 尺寸 传感器 侧面 导轨 的 CDM 使用 analog monitor (DC140), 和 输入 the analog 值 (最大 位置/最小 位置) checked in advance 从 the NVM 以下. 出纸 Diag 模式, 和 关闭电源, the entered analog 值 is automatically saved in the NVM in-built in the IP PWB CPU.

      [当...时 the CDM is the 连接 destination]

      • NVM 769-500: IP 纸盘 尺寸 传感器 侧面 导轨 最小 位置 Analog 值 (默认值: 634)

      • NVM 769-501: IP 纸盘 尺寸 传感器 侧面 导轨 最大 位置 Analog 值 (默认值: 71)

调整

[调整 当...时 CDM 已更换 在...之后 安装]

用于 调整, 说明 将 given 仅 用于 [调整 当...时 CDM 已更换 在...之后 安装] 和 [调整 当...时 Interposer 已更换 在...之后 安装].

  • 安装后 the Interposer, if 以下零件 是 replaced 由于 breakdown 等., 执行 以下 procedures 在...之后 parts 更换.

    • 当...时 the CDM 已更换

    • 当...时 the CDM PWB (CDM 主电路板) 已更换 (PL 43.4a, PL 43.4b)

    • 如果 analog 值 无法 be 读取 进入 CDM 从 the Interposer 由于 a 问题

  1. 连接 CDM 和 the Interposer, 和 打开电源.

  2. 输入 the Diag 模式 和 选择 [Maintenance/Diagnostics] 和 然后 [NVM 读/写].

  3. 输入 NVM [769-546] -> [确认 设置] -> "1" 进入 the 新 值 column -> [Save].

  4. 出纸 Diag 和 转动 关机 然后 ON.

    1. The analog 值 stored in the NVM in-built in the IP PWB CPU is automatically written 到 CDM NVM 769-500 (最小 位置)/769-501 (最大 位置).

      在...之后 writing the analog 值, the 值 of NVM [769-546] is automatically 设置 从 [1] -> [0].

[调整 当...时 Interposer 已更换 在...之后 安装]

  • 安装后 the Interposer, if 以下零件 是 replaced 由于 breakdown 等., 和 faults occur frequently, 执行 以下 procedures 在...之后 parts 更换.

    • 当...时 the Interposer 已更换 (PL 46.1)

    • 当...时 the IP 纸盘 组件 已更换 (PL 46.10)

    • 当...时 the IP PWB 已更换 (PL 46.3)

    • Interposer 尺寸 mismatch occurs frequently

  1. 连接 CDM 和 the Interposer, 和 打开电源.

  2. 输入 the Diag 模式 和 选择 [Maintenance/Diagnostics] 和 然后 [NVM 读/写].

  3. 输入 NVM [769-545] -> [确认 设置] -> "1" 进入 the 新 值 column -> [Save].

  4. 关闭 the Interposer 纸盘 侧面 导轨 up 到 最小 位置.

  5. 用于 the analog 值 (最小 位置) 的 IP 纸盘 尺寸 传感器 侧面 导轨 的 CDM, 检查 horizontal 宽度 的 最小 位置 和/与 DC140 [048-200].

  6. 打开 the Interposer 纸盘 侧面 导轨 up 到 最大 位置.

  7. 用于 the analog 值 (最大 位置) 的 IP 纸盘 尺寸 传感器 侧面 导轨 的 CDM, 检查 horizontal 宽度 的 最大 位置 和/与 DC140 [048-200].

  8. 输入 the analog 值 (最小 位置: B5 SEF 值)/(最大 位置: A4 LEF 值) confirmed beforehand 和/与 NVM 769-500 (最小 位置)/769-501 (最大 位置) 的 CDM.

  9. 出纸 Diag 和 转动 关机.

    1. The entered analog 值 is automatically saved in the NVM in-built in the IP PWB CPU.

      在...之后 writing the analog 值, the 值 of NVM [769-545] is automatically 设置 从 [1] -> [0].
