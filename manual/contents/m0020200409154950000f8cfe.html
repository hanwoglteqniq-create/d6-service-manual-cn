6.2.4.6 HCS, EDIM Basic 配置 

  • 大容量堆叠器 (HCS)

    It is a functional 模块 该 可以 执行 以下 operations on 纸张 输出 从 the preceding stage functional 模块 基于 输出 destination designation (序列号 通信) 从 the CDM.

    • 高 容量 纸盘 用于 堆叠 (堆叠器 纸盘, 哪个 可以 load 5000 纸张)

    • 输出 到顶部 纸盘. (堆叠器 纸盘, 哪个 可以 load 500 纸张)

    • 传输 到 latter 功能模块. (手送 传输 用于 connecting to a subsequent 设备)

(图 1) sa623002

  • 大容量堆叠器 (EDIM) 和/与 传输 模块

    Change the 纸张传输 高度 by 设置 the 手送 传输 路径 to straight 输出, 和 传输 it 到 3rd Party 装订器 in the subsequent stage.
