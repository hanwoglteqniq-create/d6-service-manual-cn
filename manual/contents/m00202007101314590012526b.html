024-963 打孔 Dust 满载/完整 

参考BSD:CH17.20

打孔 Waste Container is 满载/完整.

原因/措施

  1. Discard 纸张 strips 从 打孔 Waste Container.

  2. 检查 values 以下 NVM:

    • NVM [763-063] (打孔 计数): 默认值 = 0

    • NVM [763-064] (打孔 Dust 附近 满载/完整 检测 计数): 默认值 = 1,550,000 (1=0.01 时间)

    • NVM [763-066] (打孔 Dust 满载/完整 检测 计数): 默认值 = 1,700,000 (1=0.01 时间)

  3. 检查 打孔 Waste Container 设置 传感器 (DC330 [012-207]) 用于 操作 故障. (PL 27.1)

    • 输入 the Diag 模式, 输入 DC330 [012-207] 和 转动 开启. 拉出 然后 插入 打孔 Waste Container to 检查是否 输出 显示 of 传感器 切换.

  4. If 编号 问题 发现, 更换 打孔 PWB. (PL 27.32)
